      Voice
      
        
      Three kinds of voice. My clone and the other ElevenLabs voices cost ElevenLabs credits per character; the Microsoft voices are free. Students see a label that matches the voice: "AI voice made from my recordings." only for my clone, "AI voice (a stock voice, not mine)." for any other voice, and no voice label for captions only. Changing the voice means each answer's audio is made fresh the next time it plays.

        Limits and access
        
        
        
          
        
            
        
              
              
              
        Characters sent to ElevenLabs per day (this costs money). Past the cap, answers continue with captions only, or with the free fallback voice if it is on. Zero turns ElevenLabs off.
        
            
        
            
        
              
              
              
        Characters spoken by the free Microsoft voices per day. They cost nothing, but the service is free, so keep a ceiling. One visitor can use at most a quarter of either cap.
        
            
        
            
            
        
            
        Per-visitor limits
        
            
        
          
        
          
        
            
        
              
              
            
        
            
        
              
              
            
        
            
        At least 6 characters. The server stores only a hash. Students already signed in keep access until their session cookie runs out.
        
            
            
        
          
        
        
        

        
        Web answers (beyond my slides)
        
        
        
          
        When no slide covers a question but it is about AI, data, agents or coding tools (for example "How do I set up n8n?"), the twin can answer from a live web search with the active model. The card is labeled "Beyond my slides: from the web", shows 2 to 4 source links and the closest slides in my course, and is never read in my voice clone. Off-topic and logistics questions are never answered from the web.
        
          
        
            
        
              
        
              
        
                
                
                
        
              
        
            
        
            
        
              
              
              
        Off means text only. Only the free Microsoft voices are offered; students see "AI voice (a stock voice, not mine)." next to the Listen button.
        
            
        
          
        
          
          
        
        
        

        
        Answer thresholds
        
        
        
          
        Every question is scored against every slide and Canvas page with cosine similarity (the score from rank(), the same Top score shown in Activity). Measured so far, across two 10-question checks: on-topic questions scored 0.543 to 0.712 and off-topic ones 0.377 to 0.509. Higher thresholds decline more real questions; lower ones let off-topic questions through. How the thresholds were chosen. After a change, run an eval to check it. Changes reach every server within 30 seconds.

          Prompts
          
        
          Every instruction a model gets. Pick one, edit it, test the draft on a question, then save it with a note. Every saved version is kept, and any one can be restored.
          
        
          These prompts change what students hear. A saved prompt is live for new questions within 30 seconds. The safety checks in code still run on every answer, whatever a prompt says: grounding in the slides and the injection check, word and character caps, slide id checks, PG language, access codes, and no student names. An answer that fails them falls back to the slide's speaker notes.

Smoke checks, evals and model tests are left out of the student numbers unless you show them; their spend is always counted.

              Label topics
              
        
              One call to a small model on the active provider groups the newest student questions (scrubbed text only, test traffic left out) into themes. At most 300 questions and 10 runs a day. Each run is kept in private storage.

              Evals
              
        
              Grade the twin on real student questions. Pick the models that answer (each runs the real ask path, with no change to the live model) and the models that judge (each scores six dimensions from 1 to 5 and gives a pass or fail). How evals work.
              
        
              Question text is de-identified and private: it lives only in the private bucket, shows only here behind the admin passcode, and never goes in git or a public link.

                                Student alerts
                                
        
                                When a student reports a broken quiz, a broken submission, or an API key out of credits, the twin texts my cell with the course, the Canvas item, and a short scrubbed quote (no names, no ids). Texts go through Twilio. If Twilio is not set up or a text fails, the alert still shows here.
                                
        
                                
          
                                
            
                                
              
                                Off: the student is asked to email me or the TA, and nothing is stored or sent.
                                
            
                                
              
              
              
                                Past the cap, alerts are stored here but not texted. The same problem in the same course is texted once per 2 hours, and each student can raise one alert a day.
